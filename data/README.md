# Datos

Esta carpeta existe solo en la copia local. Su contenido está excluido en `.gitignore`.

Estructura esperada cuando se tenga acceso a los audios:

```
data/
├── raw/        # audios originales, sin modificar
├── interim/    # audios normalizados (16 kHz, mono, WAV)
└── processed/  # segmentos alineados con su transcripción
```

Antes de copiar cualquier archivo aquí, confirma con la Dra. Estrada las condiciones de uso acordadas.
